### Overview

Sara Sparkle provides a compact way to indicate AI-assisted functionality and progress. Use Sara Sparkle to highlight actions assisted by AI or information generated by AI, offering clear visual feedback about AI operations and their current status.

<RenderBlock of={SaraSparkleStories.All} />

### States

Sara Sparkle has **4 states** - default, listening, short processing and long processing.

<RenderBlock of={SaraSparkleStories.States} />

### Sizes

Sara Sparkle supports **4 pre-defined sizes** - tiny (16px), regular (24px), medium (32px) and large (48px). Sara Sparkle's size can also be customized to meet specific design requirements.

### Usage Guidelines

#### When to Use Sara Sparkle

- **AI-Assisted Actions**: Use for actions assisted or powered by AI like auto-filling, content generation, or modification
- **Progress Indication**: Use as a progress indicator to provide real-time feedback on AI operations
- **AI-Generated Content**: Use to highlight information or content that has been generated by AI
- **Contextual AI Features**: When you need to indicate AI functionality within specific workflows

#### Sara Sparkle for AI Assisted Actions

Use Sara Sparkle for actions assisted or powered by AI like auto-filling, content generation, or modification. These actions can either be direct or indirect, providing users with clear visual indicators of AI involvement.

#### Sara Sparkle as Progress Indicator

The Progress Indicator provides real-time feedback on the AI's status, showing when it is listening, processing, or idle. This helps users understand the current state of AI operations.

#### States Usage

- **Default State**: Use when AI functionality is available but not currently active
- **Listening State**: Use when the AI is actively receiving input or waiting for user interaction
- **Short Processing State**: Use for quick AI operations that complete within seconds
- **Long Processing State**: Use for complex AI tasks that require substantial time to complete

#### Size Guidelines

- **16px (Tiny)**: Use for minimal space constraints and subtle AI indicators
- **24px (Regular)**: Use for standard UI elements and most common implementations
- **32px (Medium)**: Use when Sara Sparkle needs moderate prominence in the interface
- **48px (Large)**: Use for primary AI features and when high visibility is required
- **Custom Sizes**: Use larger custom sizes when Sara Sparkle is a focal point or for specialized interfaces

#### Processing States

- **Long Processing**: Use for tasks that require substantial duration to complete, providing users with clear expectations about wait times
- **Short Processing**: Use for concise processes that complete quickly, maintaining user engagement without over-communicating
