### Overview

AI Icon Button provides a compact way to initiate AI-powered actions when space is limited and the icon meaning is universally understood. The distinctive sparkle indicator signals to users that the action utilizes AI capabilities.

<RenderBlock of={AIIconButtonStories.All} />

### States

AI Icon Button supports **5 states** - default, hover, active, focus and disabled.

### Usage Guidelines

#### When to Use AI Icon Button

- **Space Constraints**: Use when there's limited space but you need to indicate AI functionality
- **Universal Icons**: Ensure the icon meaning is universally understood by users
- **Secondary AI Actions**: For AI actions that don't require primary emphasis but need clear identification

#### Sparkle Positioning

The sparkle icon aligns with the edges of the icon container and can be positioned based on your layout needs:
- **Top Position**: Use when the sparkle won't interfere with other UI elements above
- **Bottom Position**: Use when you need to avoid visual conflicts with elements positioned above the button
