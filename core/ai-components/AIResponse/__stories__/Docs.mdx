### Overview

AI Response serves as a communication interface between the AI assistant (Sara) and users, providing a structured and interactive way to display AI-generated content. It supports various configurations including avatars, metadata, action buttons, and custom content.

### Sub-components

#### AIResponse.Body

Contains the main content of the AI response. Can include text, images, and other rich content.

#### AIResponse.ActionBar

Provides action buttons for user interaction such as copy, regenerate, like/dislike, and additional menu options.

#### AIResponse.Button

Individual action buttons within the ActionBar, supporting various icons, states, and interactions.

### Usage Guidelines

#### When to Use AI Response

- **AI Communication**: Use when displaying any response or information generated by an AI system
- **Conversational Interfaces**: Essential for chat-like interactions with AI assistants
- **Content Generation**: When showing AI-generated content that users can interact with
- **Feedback Collection**: When you need to gather user feedback on AI responses

#### Avatar Usage

- **Show Avatar**: Use when establishing clear AI identity or in multi-agent conversations
- **Hide Avatar**: Use in compact interfaces or when AI context is already established

#### Action Bar Guidelines

- **Include Standard Actions**: Provide copy, regenerate, and feedback buttons for comprehensive interaction
- **Tooltip Usage**: Always include tooltips for icon-only buttons to ensure accessibility
- **Contextual Actions**: Add relevant actions based on the type of content being displayed

#### Feedback Implementation

- **Enable Feedback**: Always provide thumbs up/down options for AI responses
- **Detailed Feedback**: Allow users to provide specific feedback categories and comments
- **Visual Feedback**: Provide immediate visual confirmation when feedback is submitted

#### Content Guidelines

- **Progressive Generation**: Show content as it's being generated for natural conversation flow
- **Rich Content Support**: Utilize custom content capabilities for images, cards, and complex layouts
- **Loading States**: Use placeholder content during generation to maintain user engagement

#### Visual Considerations

- **Glow Effect**: Disable glow in visually busy interfaces to reduce distraction
- **Spacing**: Maintain consistent spacing between avatar, content, and metadata
- **Responsive Design**: Ensure proper behavior across different screen sizes
