## Structure

### Technical Specifications

**Round Avatar:**
- Height/Width: 24px (tiny), 32px (regular)
- Shape: Circular

**Square Avatar:**
- Height/Width: 24px (tiny), 32px (regular)
- Corner radius: 4px

## Configurations

### Props

- **appearance**: Controls the color scheme (primary, secondary, alert, warning, success, accent1-4)
- **size**: Sets the avatar size (tiny, regular)
- **shape**: Defines the avatar shape (round, square)
- **firstName/lastName**: Used for generating initials when no image/icon is provided
- **withTooltip**: Enables tooltip display on hover
- **disabled**: Applies disabled styling and behavior
- **presence**: Shows presence indicator (active, away)
- **status**: Displays custom status indicator
- **tooltipSuffix**: Appends additional text to the tooltip

## Best Practices

### Color Assignment
Background colors are generated dynamically and should remain consistent for each entity throughout the application.

### Fallback Hierarchy
The component follows this fallback order:
1. Custom image/icon
2. Generated initials from firstName/lastName
3. Default placeholder

### Usage Guidelines
- Use round avatars for individual users, bots, or apps
- Use square avatars for groups or organizations
- Avoid using square avatars near icon buttons to prevent confusion
- Use appropriate background colors for PNG/SVG images without backgrounds
- Add tooltip suffixes for disabled states to inform users
