## Overview

AvatarGroup is used to display multiple user avatars in a condensed format. It automatically handles overflow by showing a count of additional users when the group exceeds the maximum display limit. Users can view additional details through an interactive popover.

## Technical Specifications

### Props Configuration
- **size**: `"regular" | "tiny"` - Controls avatar dimensions (default: `"regular"`)
- **max**: `number` - Maximum avatars to display before showing count (default: `2`)
- **borderColor**: `string` - Custom border color for avatars
- **list**: `AvatarData[]` - Array of user data objects
- **popoverOptions**: `object` - Configuration for overflow popover behavior

### Popover Settings
- **width**: Customizable width (default: 176px for avatar group)
- **maxHeight**: Maximum height constraint (default: 256px)
- **position**: Popover placement relative to trigger
- **on**: Interaction trigger - `"hover" | "click"`
- **withSearch**: Enable search functionality within popover
