### Overview

Badge helps the users to understand the difference between multiple entities by displaying concise metadata of that entity as a label.

<RenderBlock of={BadgeStories.All} />

### Variants

Badge comes in **2 variants** based on their visual weight – solid and subtle.

#### Solid Badge

Solid style is used to highlight important information on the page so that they can be recognized easily. Solid style helps the badge to easily pop out in a page.

<RenderBlock of={BadgeStories.SolidWarning} />

#### Subtle Badge

Subtle style is used when a lot of entities on a single page need tagging/labelling. In that case, using solid badges becomes a bit overwhelming e.g. tags in a list. This is why subtle badges use the lightest shade of the colors.

<RenderBlock of={BadgeStories.SubtleWarning} />

### Usage

#### Spacing Between Badges
Badges should maintain a **minimum spacing of 8px** from the content on either side to ensure proper visual separation and readability.

#### Solid vs Subtle
Use solid badges to highlight important information that needs to stand out on the page. Use subtle badges when tagging multiple entities on a single page to avoid visual overwhelming.
